# Hand-written connectors

Elasticsearch sinks for every registered event are generated by
`apps/bootstrap/src/connect.py` (run with `make sink`), so they don't live here.

Put any *extra* connector configs in this folder as `<file>.json`:

```json
{ "name": "my_connector", "config": { "connector.class": "...", ... } }
```

`make sink` applies them after the generated sinks, and `bin/kc status <file>` works with them.
